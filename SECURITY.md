# Security policy

## Supported versions

Security fixes are issued for the latest minor release. Critical actuator-safety fixes may also receive a patch for the preceding minor release.

## Reporting

Do not open a public issue for a vulnerability. Use GitHub private vulnerability reporting for `onlybrezel/botparty-client`. Include the affected version, adapter/platform, impact, reproduction and any known safe-state behavior. Do not include production credentials or user data.

Expect acknowledgement within three business days and an initial severity assessment within seven. Coordinated disclosure follows a verified fix and operator notice. Immediate physical-safety risk may require disabling the affected feature before a full patch is available.

## Scope

The client, installer, release verification, OTA, device identity, local endpoints and bundled adapters are in scope. Third-party services and unmodified vendor hardware should be reported to their owner; reports showing a client integration impact remain welcome.
